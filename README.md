# Тадар — шорский язык играючи

Веб-версия (PWA) приложения «Тадар» по презентации проекта СПбПУ: игровое изучение шорского языка в стиле Duolingo — уроки по 5 минут, эпос кай как награда, «Голоса старших», режимы «Класс» и «Путешественник». Маскот — волчонок Пӧрӱ из презентации.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр сборки: http://localhost:4173
```

Сборка в `dist/` — статические файлы с относительными путями: их можно выложить на GitHub Pages, Netlify, Vercel или любой хостинг. Маршрутизация через `#/…`, поэтому настройка сервера не нужна. На HTTPS приложение ставится на телефон как PWA и работает офлайн.

### Vercel и GitHub Pages

Vercel определяет Vite сам: подключите репозиторий, и каждый push в `main` будет публиковаться автоматически.

Для GitHub Pages есть workflow `.github/workflows/deploy.yml` с ручным запуском. Включите **Settings → Pages → Build and deployment → Source: GitHub Actions** и запустите workflow во вкладке **Actions**. Адрес будет вида `https://<пользователь>.github.io/tadar/`.

### Сервер (Supabase)

Без сервера «Тадар» работает целиком на устройстве: соперники в лиге и ученики класса — учебные, записи голосов остаются в браузере. С сервером лиги, классы и «Голоса старших» становятся общими для всех, а прогресс сохраняется в аккаунте. Аккаунт создаётся сам после знакомства — гостевой, без почты и паролей; почту можно привязать в настройках, чтобы продолжать на другом устройстве.

1. Создайте проект на [supabase.com](https://supabase.com) (бесплатный тариф подходит).
2. **SQL Editor** → вставьте файл [`supabase/migrations/20261002000000_tadar.sql`](supabase/migrations/20261002000000_tadar.sql) целиком → **Run**. Скрипт можно запускать повторно.
3. **Authentication → Sign In / Providers** → включите **Allow anonymous sign-ins**.
4. **Authentication → Rate Limits** → поднимите лимит гостевых входов (по умолчанию 30 в час с одного IP), иначе класс из одной школьной сети не войдёт разом. Хватит 300.
5. **Authentication → URL Configuration** → **Site URL**: адрес сайта, например `https://tadar-sooty.vercel.app`.
6. Для входа по почте: **Authentication → Emails → Templates** — в шаблоны **Magic Link** и **Change Email Address** добавьте код `{{ .Token }}` (приложение просит ввести код из письма; ссылка из письма тоже работает). Встроенная почта Supabase отправляет всего несколько писем в час — для класса подключите свой SMTP (**Authentication → Emails → SMTP Settings**, подойдёт бесплатный тариф Resend или Brevo).
7. **Project Settings → API Keys**: скопируйте Project URL и публичный ключ (anon / publishable). В Vercel: **Settings → Environment Variables** → `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` → **Redeploy**. Для локального запуска — файл `.env.local` по образцу `.env.example`.
8. Модераторы «Голосов старших» (носитель языка, преподаватель): в приложении **Настройки → Аккаунт → ID аккаунта → Копировать**, затем в SQL Editor:
   ```sql
   update public.profiles set role = 'moderator' where id = 'вставьте-id';
   ```
   У модератора на странице «Голоса старших» появится очередь проверки.

**Сколько места занимает.** Всё сделано под бесплатный тариф: прогресс ученика — одна строка JSON, даже у ученика, прошедшего весь курс за год, это ≈9 КБ в базе (обычно 2–4 КБ); профиль и строка лиги — сотни байт. Итого 5–12 КБ на ученика: 50 МБ базы хватает на несколько тысяч учеников. Записи голосов лежат в Storage: файл не больше 400 КБ (проверяется сервером), а на деле 15–40 КБ — запись с микрофона идёт в Opus 32 кбит/с, большие файлы из диктофона обрезаются по тишине до 15 секунд и пережимаются. Отклонённые записи удаляются вместе с файлом, у одного человека — не больше 300 записей. Результаты уроков пишутся только для учеников, состоящих в классе. В конце миграции есть необязательная еженедельная чистка (pg_cron): старые недели лиги и гостевые аккаунты, не заходившие 120 дней.

Доступ защищён RLS: каждый меняет только свои данные, учитель видит только своих учеников, непроверенные записи видят только автор и модераторы, роль модератора из приложения не поменять.

### Страница в claude.ai

`npm run artifact` собирает `dist/tadar-app.html` — версию страницы для публикации артефактом claude.ai (без обёртки документа). Там прогресс сохраняется в личном хранилище зрителя, а записи «Голосов старших» загружаются файлами: микрофон во встроенном окне недоступен.

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Учиться** | Карта из 11 разделов и 45 уроков: узлы-уроки, сундуки с орешками, узел эпоса в конце раздела, справочник по грамматике к каждому разделу |
| **Урок** | 10 типов заданий: новое слово, выбор перевода, картинки, аудирование, пары, сборка фразы, пропущенное слово, письмо с шорской клавиатурой (ғ қ ң ӧ ӱ), запись на слух. Сердца, комбо, повтор ошибок в конце, экраны итогов и серии |
| **Эпос кай** | 11 фрагментов-пересказов шорских сказаний — награда за разделы. Музыка (горловой гул, кай-комус, варган) синтезируется в браузере, строки подсвечиваются, шорские слова озвучиваются |
| **Голоса старших** | Запись слов с микрофона или из файла, данные о говорящем. С сервером — общий аудиословарь: запись сжимается до 15–40 КБ, уходит на проверку модератору и после одобрения звучит в уроках у всех |
| **Лига, задания, лавка** | Недельная лига (6 лиг с шорскими названиями) — с сервером это настоящие группы до 30 учеников, таблица обновляется у всех сразу. 3 задания в день, достижения, кедровые орешки (қузуқ): заморозка серии, сердца, двойной опыт |
| **Класс** | Учитель: несколько классов, код и QR-код для учеников, задания со сроками, живая таблица учеников (опыт за неделю, уроки, точность, задания), экспорт CSV. Ученик: вступление по коду или QR, задания на карте уроков, рейтинг класса |
| **Путешественник** | Мини-курс, схематическая карта Горной Шории с толкованием названий, разговорник с озвучкой, QR-коды мест для курорта |
| **Ещё** | Словарь (228 слов, поиск без особых букв), алфавит и звуки, профиль с календарём, настройки (тема, голос, цель, режим) |

## Контент и источники

- Вся лексика и примеры сверены со словарями проекта «Тадар тили» (tili.tadarlar.ru) и шорскими статьями Викисловаря; 496 шорских строк проверены скриптом — каждая найдена в словарях.
- Предложения для упражнений — примеры из словарных статей и учебных диалогов.
- Эпос — краткие пересказы сюжетов (по «Шорскому героическому эпосу», сост. Д. А. Функ, 2010, записям В. В. Радлова и Н. П. Дыренковой), а не переводы.
- Перед реальным выпуском уроки нужно проверить с носителем и преподавателем — так и заложено в презентации.

Где менять контент:

- `src/data/vocab.ts` — слова (написание, перевод, эмодзи, пояснения);
- `src/data/sentences.ts` — предложения с подсказками к каждому слову;
- `src/data/course.ts` — разделы, уроки и справочник;
- `src/data/epics.ts` — фрагменты эпоса и параметры музыки;
- `src/data/travel.ts` — места на карте и разговорник;
- `src/ui/pics.ts` — рисунки к словам и достижениям (SVG 48×48 в палитре приложения; ключ — эмодзи из словаря, без рисунка показывается сам эмодзи);
- имя маскота — `MASCOT_NAME` в `src/ui/kit.tsx`.

## Озвучка

Шорских голосов у браузеров пока нет. Слова читает ближайший тюркский голос (турецкий, казахский) через транслитерацию, а без них — русский. Голос и скорость выбираются в настройках. Кнопка с черепахой читает медленно и по слогам (э-зен, чат-чаң), как учитель на уроке. Записи «Голосов старших» автоматически заменяют синтез.

## Ограничения демо

- Без сервера прогресс хранится на устройстве (localStorage, IndexedDB), а ученики класса и соперники в лиге сгенерированы для примера. С сервером всё это настоящее — см. «Сервер (Supabase)».
- Музыка кая синтезирована. Позже её заменят записи исполнителей.

## Структура

```
src/
  data/        контент курса
  lesson/      генератор и компоненты упражнений
  pages/       экраны приложения
  state/       состояние, прогресс, игровые правила
  net/         сервер: вход, синхронизация, лига, классы, общий аудиословарь
  audio/       звуки, озвучка, синтез кая, записи
  ui/          иконки, маскот, орнамент, общие компоненты
  styles/      стили (светлая и тёмная тема)
public/        маскот, иконки PWA, манифест, сервис-воркер
supabase/      схема базы, права доступа (RLS), хранилище записей
```
